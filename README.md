# Voyage — studio website

Static single-page site for Voyage (voyage-studio.com). No build step: edit `index.html`, commit, and GitHub Pages redeploys.

- `index.html` — the whole site (HTML, CSS and JS inline)
- `logo-mark.png`, `wordmark.png` — brand assets, taken from `Branding/Final/4K.png`
- `kona.jpg`, `kona2.jpg` — trailer thumbnails
- `CNAME` — custom domain for GitHub Pages
